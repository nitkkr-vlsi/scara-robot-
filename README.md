# SCARA Robot Control and Automation

Arduino-based control of a SCARA (Selective Compliance Assembly Robot Arm) developed during a summer internship at IHFC, IIT Delhi, with Gravitaz Automation Pvt. Ltd.

## Project Overview

This project focuses on controlling a three-axis SCARA robot using an Arduino Uno, stepper motors, and motor drivers.

## Hardware Used
- Arduino Uno
- Three stepper motors
- TB6600 stepper motor drivers

## Software and Tools
- Arduino IDE
- AccelStepper library
- GeoGebra
- Wokwi

## Code Features
- Stepper motor control using STEP and DIR signals
- Forward and inverse kinematics routines
- Serial commands for selecting motion modes
- Position storage using EEPROM
- Motor speed and acceleration settings
- Position reporting through serial communication
